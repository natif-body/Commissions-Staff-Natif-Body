# 💪 NutriPure - Gestion des Commissions Coachs

Application web pour gérer les ventes et commissions des coachs NutriPure.

## 🚀 Fonctionnalités

### 📝 Mode Saisie
- Sélection du mois et du coach
- Ajout/modification des quantités vendues par produit
- Calcul automatique des ventes et commissions en temps réel
- Barre de recherche pour trouver rapidement un produit
- Indicateurs visuels :
  - 🟨 Jaune : < 300€ de ventes = **10% de commission**
  - 🟩 Vert : ≥ 300€ de ventes = **15% de commission**

### 📊 Dashboard
- Vue d'ensemble des performances de chaque coach
- Cartes individuelles avec totaux annuels
- Tableau détaillé mois par mois
- Calcul automatique des commissions
- Visualisation des tendances

## 💾 Sauvegarde
Les données sont automatiquement sauvegardées dans le navigateur (LocalStorage). Aucune connexion internet requise après le premier chargement.

## 🌐 Déploiement

### Option 1 : GitHub Pages (Recommandé)
1. Forkez ou clonez ce repository
2. Allez dans Settings > Pages
3. Sélectionnez la branche `main` et le dossier `/ (root)`
4. Votre application sera disponible à : `https://votre-username.github.io/nutripure-commissions/`

### Option 2 : Local
1. Téléchargez le fichier `index.html`
2. Ouvrez-le dans votre navigateur
3. C'est tout ! 🎉
